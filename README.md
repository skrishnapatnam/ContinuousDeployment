# ContinuousDeployment

Contains:

- **`sports-highlights/`** — **PlayTape**, a Next.js app that aggregates legal sports highlights from official YouTube channel feeds (soccer, cricket, NBA, NFL, MLB, and more).
- **`kalshi-alert-agent/`** — eve agent + dashboard that continuously scans [Kalshi](https://kalshi.com) for the highest-probability contracts that still pay money.
- **`ContinuousWeb/`** — existing ASP.NET sample site.
- **`Tests/`** — sample tests for ContinuousWeb.

See [`sports-highlights/README.md`](./sports-highlights/README.md) to run PlayTape, or [`kalshi-alert-agent/README.md`](./kalshi-alert-agent/README.md) for the Kalshi monitor.
